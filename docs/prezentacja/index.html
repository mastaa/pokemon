Czym jest Kubernetes?

Orkiestrator kontenerów – uruchamia, skaluje, naprawia i łączy kontenery na wielu maszynach.

  • samonaprawianie (restart, przeniesienie)
  • skalowanie poziome
  • rolling update i rollback
  • service discovery i load balancing
  • zarządzanie konfiguracją i sekretami

Model deklaratywny

Nie mówimy „uruchom 2 kontenery”.
Mówimy „ma działać 2 kontenery”.

Kontrolery w pętli porównują stan pożądany (YAML) ze stanem faktycznym i niwelują różnicę.

kubectl apply -f plik.yaml

Dockerfile

branch k8s/01-dockerfile

Obraz → Kontener → Pod

  • Obraz – niezmienny szablon: system + runtime + aplikacja
  • Kontener – uruchomiona instancja obrazu
  • Pod – najmniejsza jednostka K8s: 1..N kontenerów ze wspólną siecią (IP) i wolumenami

Kubernetes nie uruchamia jarów ani kodu – uruchamia kontenery z obrazów.

 Dockerfile
     │ docker build
     ▼
 obraz poke:1.0.0
     │ k3d image import / docker push
     ▼
 ┌─────── Pod ───────┐
 │ IP: 10.42.0.5     │
 │ ┌───────────────┐ │
 │ │ kontener poke │ │
 │ │    :8080      │ │
 │ └───────────────┘ │
 └───────────────────┘

Dockerfile – build wieloetapowy

# ---------- 1) FRONTEND ----------
FROM node:24-alpine AS frontend
WORKDIR /workspace/frontend
COPY frontend/package.json frontend/package-lock.json ./
RUN npm install --no-audit --no-fund            # warstwa cache'owana
COPY frontend/ ./
RUN npx ng build                                 # -> ../src/main/resources/static

# ---------- 2) BACKEND ----------
FROM eclipse-temurin:25-jdk AS backend
WORKDIR /workspace
COPY gradlew settings.gradle build.gradle ./
COPY gradle/ gradle/
RUN ./gradlew --no-daemon dependencies > /dev/null
COPY src/ src/
COPY --from=frontend /workspace/src/main/resources/static/ src/main/resources/static/
RUN ./gradlew --no-daemon bootJar -x npmInstall -x buildFrontend && cp build/libs/*-SNAPSHOT.jar app.jar

# ---------- 3) RUNTIME ----------
FROM eclipse-temurin:25-jre-alpine
RUN addgroup -S -g 1000 app && adduser -S -u 1000 -G app app
COPY --from=backend --chown=app:app /workspace/app.jar /app/app.jar
USER 1000:1000
ENV JAVA_TOOL_OPTIONS="-XX:MaxRAMPercentage=75.0"
EXPOSE 8080
ENTRYPOINT ["java", "-jar", "/app/app.jar"]

Budowanie i dobre praktyki

docker build -t poke:1.0.0 .
docker images poke

# test lokalny
docker run --rm -p 8080:8080 \
  -e APP_ENVIRONMENT=docker poke:1.0.0
curl localhost:8080/api/info

# obraz do klastra
k3d image import poke:1.0.0 -c workshop
# kind load docker-image poke:1.0.0
# minikube image load poke:1.0.0
  • multi-stage – w obrazie nie ma Node, Gradle, JDK
  • kolejność warstw – zależności przed kodem
  • non-root – USER 1000
  • .dockerignore – bez node_modules, .git, build/
  • JVM w kontenerze – MaxRAMPercentage
  • konkretny tag, nie latest

Namespace – logiczna izolacja nazw, uprawnień i łatwe sprzątanie:
kubectl delete ns poke

deployment.yaml

spec:
  replicas: 2
  selector:
    matchLabels:
      app.kubernetes.io/name: poke
  strategy:
    type: RollingUpdate
    rollingUpdate: { maxSurge: 1, maxUnavailable: 0 }
  template:
    metadata:
      labels:
        app.kubernetes.io/name: poke  # = selector!
    spec:
      securityContext: { runAsNonRoot: true, runAsUser: 1000 }
      containers:
        - name: poke
          image: poke:1.0.0
          imagePullPolicy: IfNotPresent
          ports:
            - { name: http, containerPort: 8080 }
          resources:
            requests: { cpu: 250m, memory: 384Mi }
            limits:   { memory: 512Mi }
          startupProbe:
            httpGet:
              { path: /actuator/health/liveness, port: http }
            periodSeconds: 2
            failureThreshold: 30
          livenessProbe:
            httpGet:
              { path: /actuator/health/liveness, port: http }
            periodSeconds: 10
          readinessProbe:
            httpGet:
              { path: /actuator/health/readiness, port: http }
            periodSeconds: 5

Probe'y i zasoby

ElementPytanieSkutek niepowodzenia
startupProbeCzy aplikacja już wystartowała?wstrzymuje pozostałe probe'y; po limicie – restart
livenessProbeCzy proces żyje (nie zawiesił się)?restart kontenera
readinessProbeCzy może przyjmować ruch?Pod wypada z Service (bez restartu)
requestsIle zarezerwować na węźle?scheduler nie znajdzie miejsca → Pending
limits.memoryIle maksymalnie?OOMKilled

maxUnavailable: 0 + readiness = zero-downtime deploy: stary Pod znika dopiero, gdy nowy jest Ready.

Ingress + Traefik

branch k8s/07-ingress-traefik · k8s/ingress.yaml, k8s/middleware.yaml

Dlaczego Ingress?

Service: LoadBalancer per aplikacja = 1 publiczne IP per aplikacja, brak routingu L7.

Ingress

  • reguły HTTP: host / ścieżka → Service
  • TLS, nagłówki, przekierowania, rate limit
  • jedno wejście, wiele aplikacji

Ingress Controller

Program, który realizuje reguły – u nas Traefik (domyślny w k3s/k3d).

 Internet / przeglądarka
   │ http://poke.localhost:8081
   ▼
 k3d loadbalancer :8081
   ▼
 Traefik (kube-system) :80
   │ Ingress: Host = poke.localhost
   │ Middleware: security-headers
   ▼
 Service poke:80
   ▼
 Pody poke :8080

ingress.yaml + Middleware

apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: poke
  namespace: poke
  annotations:
    traefik.ingress.kubernetes.io/router.entrypoints: web
    traefik.ingress.kubernetes.io/router.middlewares: \
      poke-security-headers@kubernetescrd
spec:
  ingressClassName: traefik
  rules:
    - host: poke.localhost
      http:
        paths:
          - path: /
            pathType: Prefix
            backend:
              service:
                name: poke
                port: { name: http }
  # tls: [{ hosts: [poke.example.com], secretName: poke-tls }]
apiVersion: traefik.io/v1alpha1
kind: Middleware
metadata:
  name: security-headers
  namespace: poke
spec:
  headers:
    frameDeny: true
    contentTypeNosniff: true
    customResponseHeaders:
      X-Workshop: "pokedex-k8s"
kubectl apply -f k8s/middleware.yaml
kubectl apply -f k8s/ingress.yaml
curl -i http://poke.localhost:8081/api/info
BASE_URL=http://poke.localhost:8081 \

Wariant: IngressRoute (CRD Traefika)

apiVersion: traefik.io/v1alpha1
kind: IngressRoute
metadata:
  name: poke
  namespace: poke
spec:
  entryPoints: [web]
  routes:
    - match: Host(`poke.localhost`)
      kind: Rule
      middlewares: [{ name: security-headers }]
      services: [{ name: poke, port: http }]
    - match: Host(`api.poke.localhost`) && PathPrefix(`/api`)
      kind: Rule
      middlewares: [{ name: rate-limit }]
      services: [{ name: poke, port: http }]
  # tls: { certResolver: letsencrypt }
